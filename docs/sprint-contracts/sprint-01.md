# Sprint 01 — 인증과 데이터베이스 기반 구축

## 목표
Supabase Auth, database schema, RLS policy의 기반을 만든다.

## 완료 기준
- 사용자가 회원가입 또는 로그인을 할 수 있다.
- Supabase에 `goals` 테이블이 존재한다.
- `goals` 테이블에 RLS가 활성화되어 있다.
- 사용자는 자기 자신의 목표 데이터만 조회할 수 있다.
- `docs/SECURITY.md`에 RLS 정책이 설명되어 있다.
- `npm run verify`가 통과한다.

## 이번 Sprint에서 제외할 것
- 분석 기능
- 이메일 템플릿
- 팀 협업 기능
